# AGENTS.md

## Website Design Requirements

For every website design or redesign task:

1. Read DESIGN.md first.
2. Plan the page narrative and module responsibilities
   before changing the layout.
3. Use 4–7 core sections for typical showcase pages,
   unless the content justifies an exception.
4. Design images and text together. Use ImageGen
   when appropriate and available.
5. Implement, inspect full-page screenshots,
   and revise visible problems.
6. Preserve factual content, SEO, and functionality.
