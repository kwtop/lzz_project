    - heading "Compare the processes by geometry" [level=2]
    - generic "Route to discuss":
      - heading "CNC turning" [level=3]
      - strong: Geometry cues
      - paragraph: Rotational features such as a shaft, sleeve, disc or fitting, often arranged around an axis.
      - strong: Drawing and quote questions
      - paragraph: Define the datum axis, diameters, shoulders, grooves, threads and runout if required. Confirm whether cross-holes, flats or slots need secondary milling.
      - heading "CNC milling" [level=3]
      - strong: Geometry cues
      - paragraph: Block-like or irregular forms with pockets, slots, holes, contours and planar mounting faces.
      - strong: Drawing and quote questions
      - paragraph: Define datum faces, pocket depth, hole patterns and positional relationships. Confirm stock, clamping surfaces, setups and inspection records.
      - heading "Multi-axis machining" [level=3]
      - strong: Geometry cues
      - paragraph: Features distributed over several faces, angled faces or areas that need different tool approaches.
      - strong: Drawing and quote questions
      - paragraph: Define common datums, face-to-face and angular relationships. Review tool access, workholding and sequence against the model.
    - figure:
      - img "A metal component held in a CNC milling setup beneath the spindle."
    - heading "When does a part need more than one process?" [level=2]
    - paragraph: A shaft with cross-holes, a turned fitting with milled flats or a housing with angled faces may need more than one operation or setup. The route should preserve the relationships between critical features. Send a 3D model and controlled 2D drawing so the team can review datums, access and inspection together.
    - heading "Is 5-axis machining always more accurate?" [level=2]
    - paragraph: No single process label guarantees accuracy. Acceptance depends on the part geometry, machine and setup, datum strategy, material, finishing and measurement method. If an interface matters, state its tolerance and datum on the drawing and ask how it will be produced and checked. Any tolerance target needs feature-specific review.
    - heading "What should I include when asking for a process recommendation?" [level=2]
    - list:
      - listitem: A 3D model and the controlling 2D drawing revision.

      - listitem: Quantity for the first order and expected repeat pattern, if known.
      - listitem: Critical datums, fits, surface requirements and required inspection records.
      - listitem: Finish, packaging and required arrival date, with any standards or approvals identified.
