# Bundled site fonts

- `roboto-latin-wght-normal.woff2`: unmodified Latin weight-variable font from
  `@fontsource-variable/roboto` 5.3.0, Roboto v51. Source:
  https://registry.npmjs.org/@fontsource-variable/roboto/-/roboto-5.3.0.tgz
  License: OFL-1.1, identical to `public/fonts/LICENSE-ROBOTO-OFL-1.1.txt`.
- `roboto-condensed-bold.woff2`: unmodified copy of the existing heading font.
  Source and Apache-2.0 license: `public/fonts/NOTICE.txt` and
  `public/fonts/LICENSE-APACHE-2.0.txt`.

Vite emits content-hashed URLs for both fonts. The existing public font URLs
remain available for older pages and cached builds.
