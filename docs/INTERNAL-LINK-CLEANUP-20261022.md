# 冗余内链清理

2026-10-22，按用户对首页“Request the current certificate and scope”的反馈，检查 86 个正式页面，清理 72 页中的 114 处冗余链接。其中 18 处认证链接改为普通文字，认证事实保留。

## 清理范围

- 首页认证说明下的索取提示。
- 首页及共用首屏中的认证跳转。
- 已列出输入要求的产品、案例、服务、联系和询价区中重复的 RFQ 清单入口。
- 已说明检验内容后附加的通用检验或订单记录跳转。
- FAQ 每组答案后的链接串，以及隐私页中无关的资料导流段落。
- 产品相关阅读区内，指向同一工艺页不同锚点的重复链接。

保留主导航、页脚、页内目录、相关产品、工艺和技术指南、下载、询价及来源上下文。公司资料区仍提供实际资料预览与直接索取入口。制造事实、数值、材料、公差和交期条件继续使用现有内容。FAQ 摘要同步移除了“附带详细要求链接”的描述。
