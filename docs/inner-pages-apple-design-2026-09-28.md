# 内页视觉精修 — 2026-09-28

## 范围与原则

使用 apple-design 的清晰层级、克制反馈、触控可用性、键盘可达与减少动态效果原则。保留工业 B2B 品牌、Inter 字体、原配色、真实图片、正文、业务承诺、信息架构和 URL。没有复制 Apple 外观，没有新增依赖、图片或营销内容；未部署。

## 审查发现与处理

- 内页主标题尺度、行高不一致：统一流体字号，桌面主体标题约 52–60px，手机约 34–39px；控制字距和断行。
- 技术信息层级弱：参数标签与值区分，使用等宽数字，提高行距；保留既有数据。
- 文章目录密集：增加链接触控高度，长目录桌面限高滚动，手机自然展开。
- 表格观感过重：减轻背景和竖线，统一单元格间距、字重和数字排版。
- 筛选标签和表单文字偏小：控件文字 16px、主要控件至少 52px 高；手机筛选单列，避免选项截断。
- 按钮、卡片反馈不一致：统一短时颜色反馈、轻微按压；产品图片仅精确指针悬停时小幅放大。
- 导航细节不统一：减轻菜单阴影、收小圆角，手机菜单按钮 44px，增加打开/关闭反馈。
- 表单边界与焦点不够清晰：统一输入间距、焦点轮廓、无效输入提示和禁用状态；邮件草稿功能未改。
- 页面节奏：统一公共章节间距和阅读行长，保留已合理的分栏、照片与编辑式布局。
- 可访问性：保留减少动态效果规则，补充高对比度表现；不以动效隐藏内容。
