# LZZ Typography System

目标：清晰、精确、克制、专业，以稳定的技术信息节奏建立品牌辨识度。沿用已加载的 Inter Variable，不增加字体下载。品牌来自角色层级、宽度、间距与数字处理，而非模仿某个品牌。

所有角色的 font-family 为 `Inter Variable, Arial, sans-serif`；Data / Specification 使用独立 `--font-data` 令牌，目前同为 Inter，但开启 `lining-nums tabular-nums`。等宽数字用于比较，正文仍使用自然比例字形，不把整站改成代码字体。

字号使用 rem / clamp 实现，表格 px 是根字号 16px 时的设计参考。宽度是阅读上限，窄容器自然收缩。Display 仅用于首页主叙述；H1 是页面身份，H2 是章节，H3 是内容组，H4 是紧凑标题。HTML 标题层级不因视觉角色改变。

## 组件映射

- 首页 hero：Display + Body Large。产品页左侧名称：H1；右侧说明：H2，避免说明比产品身份更抢眼。
- 页面主标题 / 章节 / 内容组：H1 / H2 / H3。产品卡片和页脚分组：H4。
- 正文段落及列表：Body；导语：Body Large；辅助说明与面包屑：Small；图片来源：Caption。
- 菜单 / 页脚导航：Navigation；行动按钮：Button；表单标题、表头、分类标签：Label。
- 公司事实数值：Data；参数表、定义列表值、表单输入：Specification。
- 新组件可使用 `data-type="body-large"` 等显式角色。不要通过继续添加局部字号和负字距来覆盖系统。

## 数字与规格

`18,000 kg`、`220 HP`、`4×2`、`Euro VI`、`-18°C`、`ISO 9001` 仅作为排版验证样本，不代表 LZZ 产品、能力或认证事实。

单个数值和单位使用 `.type-value` 保持整体；文本可使用不换行空格，例如 `18,000 kg`。保持真正的乘号 `×`、度符号 `°`、标准缩写与大小写。数据行允许在独立字段之间换行，不对整张表使用 nowrap。数字不使用负字距，也不自动改写原始数值或单位。正文不强制 tabular-nums；技术参数使用它以便逐行比较。

## 样式所有权

`src/styles/typography-system.css` 是最终排版层。历史页面存在大量 scoped 规则，因此仅字体度量使用集中 `!important`，使角色规则拥有明确优先级；布局、颜色、图片、交互仍由原组件控制。后续新增组件应引用角色，不再增加竞争的字体规则。

本次仅本地实现，未部署。样张保存在 docs 内，不进入网站路由或 sitemap。
