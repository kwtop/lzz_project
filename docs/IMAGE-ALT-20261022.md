# 图片 alt 与分享图描述修正

2026-10-22，本地实现后已按用户授权发布至 Cloudflare 线上预览。发布记录见 cloudflare-preview-2026-10-22-alt.md。

按本轮全站图片检查清单修正 86 个正式路由的描述与分享元数据，不调整栏目、品牌色或布局。

- 153 个正文图片使用位置的 alt 更新为画面内容，包括新闻图片的 ImageGen 制作字样、generic 等制作措辞，以及 8 张图片共 16 个位置的笼统描述。
- `siteImages.generated.json`、`productPhotography.generated.json` 和能力首屏登记中的 alt 只承担内容描述；caption、origin、generator、operation、sourceReference、sourceKind、母版路径等内部来源身份继续保留。
- 澳大利亚来访的握手照片使用具体描述，源登记与生成媒体登记同步更新，来源路径与 SHA-256 不变。
- `src/data/socialImages.ts` 从图片登记中读取描述，覆盖同一图的响应式导出；三个独立栏目封面单独登记。新增分享图缺少描述时构建报错，不回退到页面标题。
- `Layout.astro` 的 86 个正式页面分享图描述全部读取实际图片内容，包括先前 66 页的标题回退。
- 材料与表面处理指南的分享图改用正文已采用的无相机水印版本。原始照片不修改、不删除。
- EX-MOUNT-01 教学图、参考面、特征编号与教学用途说明保持不变。
