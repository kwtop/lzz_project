# LZZ 整站配色规划

2026-10-20。规划范围为当前 sitemap 的 **86 个正式页面、13 类页面职责**，以及共享导航、页脚、404 和交互状态。方向采用用户给出的两张参考图：近白内容面、炭黑展示面、橙红重点与逐级橙阶。

**状态：规划与独立预览，尚未应用到正式源码或 Cloudflare。** 当前已发布基线为 [5199295d](https://5199295d.lzz-precision.pages.dev/)。布局、栏目、正文、照片身份、Logo、字体、URL、锚点、筛选与询价契约沿用现有实现。本轮没有接入后台。

## 1. 视觉规则

- 阅读、比较、填写使用近白或白色；工厂与加工媒体展示使用炭黑；短公司摘要与单一询价重点使用橙红。展示型页面通常保留 1–2 处橙红重点，长文章和表单保持浅底。
- 表面颜色跟随模块职责，保留各页既有内容顺序与数量。首页继续保留现有 13 个内容模块；长指南保留技术目录、图纸和表格。
- 图片保留原色与现有裁切；金属零件、材料和文件照片不叠橙色滤镜。摄影上的标题继续使用现有深色遮罩，需按最亮区域复核可读性。
- 配色采用平整色面与清楚边界。参考图底部的大光晕不纳入本轮，背景不增加动画。现有导航左右轻微收缩和 reduced-motion 行为保留。
- 字体继续为现有 Roboto / Roboto Condensed，尺寸、留白、圆角和容器尺寸沿用当前规范。颜色不能代替标题、编号、勾选或错误原因。

### 导航、页脚与按钮

- 叠在现有摄影上的导航保持透明底、白色 Logo 与文字；浅色页面初始使用近白底、近黑标识与文字；滚动后的导航统一为炭黑底、白色标识与文字。沿用当前判断条件及滚动阈值，保持原有缩进动画。
- 桌面下拉面板和手机菜单使用白色内容面、近黑文字，当前项采用深橙文字、浅橙底或下划线；展开箭头、键盘操作、焦点返回、滚动锁定不变。
- 页脚使用炭黑底、白色标题与 Logo，辅助文字为深底说明灰；六列栏目、联系方式和入口保持当前结构。WhatsApp 保留品牌绿。
- 主询价按钮使用深橙底、白字，hover 为 #942F16，按下为 #812912；深底按钮增加亮橙边界。橙红面上的主按钮使用炭黑底、白字、亮橙箭头，hover 为 #303030。
- 次按钮使用当前表面的文字色和可辨边界；浅底文字链接为深橙并保留下划线，深底链接可用亮橙并保留下划线。
- 浅底焦点环使用深橙，深底焦点环使用亮橙，2px 外框、3px 间隔；可点击区域至少 44px。禁用操作采用浅灰底、说明灰字与 disabled 语义。

## 4. 表单、筛选与状态

- 表单白色、控件边界 #7A7A7A；普通正文近黑、提示灰。国家继续由客户手填；默认 WhatsApp / Phone，切换 Email 保留本页输入，只提交所选渠道。三项必填、可选工艺/留言/附件、来源预选及文件限制保持当前逻辑。
- 单选、工艺多选和筛选已选项使用 #FBE6DE 浅底、深橙边框与文字，同时显示勾选或当前标记。Not sure yet 的互斥行为保留。清除筛选和重置使用可辨的文字操作。
- 错误与 Fail 使用 #9B2924、#FFF1EF 浅底和具体原因；成功与 Pass 使用 #216243、#EDF6F0 浅底和文字；提醒使用 #805100、#FFF4DC 浅底。教学检验当前使用的品牌橙 Fail 应迁移到状态红，数值、范围、判定与暂停放行逻辑不变。
- 加载、空结果与未接通使用中性灰面和说明；加载保留占位和状态文字，空结果保留恢复动作。未接后台继续明确未发送、未上传，保留输入并提供邮箱/WhatsApp。成功仍仅由真实适配器成功结果触发。
- 图像/视频弹窗使用深色遮罩、白色操作文字、亮橙焦点环；媒体本体保持原色。加载、重试、缩放、键盘循环和关闭后焦点返回沿用现有交互。
- 教学 SVG 的几何、尺寸线和基准标记不做全局重染；HTML 检验表与 CSV/SVG 下载仍由同一份现有数据生成。状态颜色不改变任何制造事实。

## 5. 实施顺序与验收

1. **先做五个代表页**：首页、工厂、一个零件详情、6061/7075 长指南、询价。建立颜色变量和表面角色，确认深浅节奏、长文可读性、照片和控件状态。
2. **迁移共享规则与剩余模板**：计划新增统一颜色入口并在 Layout.astro 加载；变量统一使用 --lzz-color- 前缀，JSON 中的 camelCase 角色名转为 kebab-case。配套 proposed-tokens.css 提供当前目标声明。为需要区分职责的既有容器添加 data-color-surface=paper|muted|dark|brand。按按钮、文字、边框、技术表与状态分别迁移当前正式样式的硬编码颜色。内部预览和历史备份不纳入迁移目标。
3. **覆盖 86 个正式路由**：按 JSON 路由表逐类推进，保持所有正文、URL、锚点、下载、图片身份与原有接口。对现有 --pn-forest 等带旧色名的变量按当前语义拆分，完成正式模板迁移后移除旧引用；不建立新旧两套配色流程。
4. **验证与交付**：执行 check、build、SEO/站内引用、询价与教学相关检查；比对换色前后文本、路由和链接，确认改动只影响预期表现。验证通过后交付本地代表页和全站记录，部署依照后续明确发布指令执行。

实施不新增后端字段、接口、存储格式或业务流程。新增的 data-color-surface 是前端表现标记，不改变公共 URL、SEO、API 或表单提交结构。

### 实施时的浏览器场景

- 320、390、768、1440px：检查首页、工厂、零件详情、长指南、询价及各类代表；无横向溢出，图片和文档原色不变，阅读和控件尺寸保持现状。
- 导航在摄影、浅底和滚动状态下可辨；桌面菜单、手机菜单、Esc 关闭、焦点返回与横向收缩不受颜色迁移影响。
- 目录筛选、组合筛选、已选项、无结果与重置；长表、FAQ 展开、教学 Pass/Fail/暂停放行；弹窗加载、错误、重试与 reduced-motion。
- 表单空提交、错误联系方式、国家手填、渠道切换、工艺多选、来源预选、不合规附件；提交中、失败、成功及未接通分别检查。未接后台不显示上传或送达成功。
- 抽查共享颜色变量、嵌套白色卡片、第三方图标与原始 SVG，防止继承导致白字落在橙底或深色字落在炭黑背景。
