# 询价表单完善

2026-10-20。按用户对 `/quote/` 的最新反馈实施，替代同日早一轮的单一联系方式表单要求。本轮仅本地实现与验证，未部署 Cloudflare，未接入真实收件、文件上传或送达服务。

后续用户已授权并完成 Cloudflare 预览发布，见 [发布记录](./cloudflare-preview-2026-10-20.md)。国家字段已按最新反馈改为手动填写；真实后台仍未接通。

## 页面与交互

[本地询价页](http://127.0.0.1:4323/quote/)

- **必填**：姓名、目的地国家、所选渠道的联系方式。目的地国家由客户手动填写，不提供下拉列表或国家建议，保留国家/地区名称的必填校验。
- **联系渠道**：`WhatsApp / Phone` 与 `Email` 两个单选按钮，默认前者。当前只显示对应的输入框；切换保留两种输入在本页中的值，提交只包含选中的渠道。电话要求国际区号。方向键可切换，焦点使用现有铜色外框。
- **可选零件类型**：外壳/盖板、轴/接头/销、块/支架/圆形件、叶轮、塑料件、汽车原型、多种零件、其他/不确定。沿用现有零件分类，避免让定制加工客户必须选择一个网站样品。
- **可选工艺**：铣削、车削、五轴、塑料加工、铸件加工，可多选。`Not sure yet` 与具体工艺互斥，客户不需要先决定加工路线。
- **来源带入**：产品引用使用现有 `partBrowseGroups` 和产品工艺分类；工艺页使用对应工艺。原始主题与来源保留，客户可以更改类型与工艺。材料、批量规划等页面不会猜测加工工艺。
- **留言与附件**：仍可留空。最多 5 个文件、合计 20 MB，支持 PDF、STEP/STP、IGES/IGS、DXF/DWG、JPG/PNG、ZIP；保留名称、大小、逐项移除与批次错误反馈。

桌面保留原有表单与联系栏；999px 及以下将联系栏移至表单后，639px 及以下姓名/国家改为竖排。保留品牌铜色、暖白背景和现有字体，未改变核心栏目、导航或页脚结构。

## 提交契约

`src/lib/inquiryForm.ts` 集中管理字段、选项、国际号码/邮箱校验、工艺互斥与附件规则；`src/lib/inquirySubmission.ts` 接收：

```ts
{
  name: string,
  destinationCountry: string,
  contact: {kind: 'phone' | 'email', value: string},
  partType: InquiryPartType | '',
  processes: readonly InquiryProcess[],
  message: string,
  attachments: readonly File[],
  context: InquiryContext
}
```

电话去除空格与分隔符后保留 `+` 和数字；国家及姓名去掉首尾空白。联系方式没有第二个隐藏提交字段，不提交未选中的号码或邮箱。输入只在当前页面内保留，刷新清空；失败、未接通及文件错误保留已接受的输入与文件。

默认适配器仍返回 `unavailable`，没有网络发送或上传行为。提交中通过 `disabled` fieldset 禁用所有表单控件并阻止重复提交；成功后锁定原表单，可重新开始并恢复入口预选值。成功、失败、等待的测试适配器位于构建目录外，未加入公开路由。

相关询价 CTA、联系页、FAQ、隐私与 SEO 描述已同步新字段。“We reply within 12 hours.” 仍指收到询盘后的首次人工回复，详细报价可能需要补充资料。
