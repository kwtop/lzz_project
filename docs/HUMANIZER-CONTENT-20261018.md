# 全站工业文案检查与修改

2026-10-18。本地实施，未部署生产。

## 范围

依据用户指定的 `humanizer:humanizer` 检查 86 个正式页面，包括 35 个产品详情、12 个 Capabilities 页面、9 个加工案例与集合页面、14 个 Resources 页面和 16 个首页、工厂、公司及公共页面。独立设计稿、历史目录和内部原始资料不改写为公开业务承诺。

71 个页面需要修改。其余页面保留已经自然、清楚且有来源支持的内容。关键词和句式扫描只用于找出待复看的内容，不判断作者，也不计算所谓 AI 率。

## 主要修改

| 问题 | 处理 |
| --- | --- |
| 反复解释来源、照片和案例“不能证明什么” | 改为零件特征、加工路线和明确的图纸、测试、验收要求 |
| 产品首段与工艺说明像同一份询价清单 | 按各零件的几何、定位面、刀具可达性和装配接口分别组织 |
| 多页重复 Potential applications 与 Your drawing defines the requirements | 说明该应用的工作接口、环境或验证要求，不冒充已供货案例 |
| 材料栏重复“未指定”“需要确认” | 直接列出订单需要指定的牌号、状态、填料、毛坯及材料记录 |
| 产品标题被 reference、CAD 等内部分类词占据 | 用清楚的零件名称；内部图片身份、来源和注册表保留 |
| 正文与搜索摘要混用 | 35 个产品页分别维护正文、卡片简介和搜索摘要；摘要 133–158 个字符，互不重复 |
| 模板化的来源说明和冗长句尾 | 删除不增加工程信息的尾句，保留具体条件与责任 |

例如，塑料页从“颜色不能证明材料及性能”改为要求指定聚合物、填料、环境、测量状态和适用测试；铸件页从“照片不能确定隐藏结构”改为用剖面、法兰基准、接口限值和测量通道定义内部特征。

## 保留的事实与条件

- 企业成立于 2017 年；15 年以上经验指工程团队；40+ 指加工及配套设备。
- 约 100,000 小件/月是参考产能，保留形状、材料、表面处理和订单组合条件。
- 1 件起订；生产为图纸和订单确认后的 7-14 个工作日，包含表面处理，运输时间另计。样件重建和图纸批准单独安排。
- ±0.01 mm 保持选定关键特征及图纸评审范围，不变成全部尺寸的保证。
- 材料选项不写成现货或照片中零件的确定牌号；C3600、C36000、H62 等不混同。
- 表面处理、尺寸检查和功能试验保留各自的验收范围；不新增压力、流量、平衡、绝缘、医疗或食品适用性结论。
- ISO 9001 及企业荣誉保留原有边界；询价仍在浏览器准备邮件草稿，由用户添加附件并发送。
