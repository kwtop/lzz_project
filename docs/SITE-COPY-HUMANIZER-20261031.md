# 全站英文表达二次复核

2026-10-31。按用户要求使用 Humanizer 3.1，在本地继续润色现有网站。本轮只修改表达，未更换图片、重排布局、部署 Cloudflare 或推送 GitHub。

## 范围与结果

以 sitemap 的 86 个正式 URL 为基线，读取实际构建正文，去除跨页完全相同的内容后逐项复核。75 页有表达调整，11 页保留原文；全部 35 个产品页有修改。保留页包括五篇公司新闻、隐私及部分已清楚的目录和服务内容，具体 URL 见逐页记录。

共修改 38 个源码文件，另更新 DESIGN.md 和 CONTENT-WRITING.md。正文从约 47,594 词变为 47,592 词；计数用于记录，不作为写作质量评分。

## 编辑内容

- 首页和服务介绍直说零件、加工动作与限制，减少抽象搭配和连续的采购指令。工厂说明由供应商解释怎样规划定位、检验和文件交付。
- 35 个产品页改写加工段落，说明夹持面、刀具进入、换装夹和测量之间的工程关系。材料牌号、处理选项、供货范围、功能测试及验收条件保留。
- 加工案例标题直接说明不同面、口袋结构或定位基准；普通介绍段落改为清楚的加工说明，技术要求清单继续使用必要的指令句。
- 采购及技术指南删除或改写几处铺垫和重复解释，保留有实际意义的技术区别、教学限制与引用。没有凭图片补写加工结果、客户评价或公司能力。
- 询价说明使用更直接的英语，继续分别说明首次人工回复、详细报价、文件传输时点与服务器保存后的成功提示。未改字段、验证、接口或提交行为。
