# 全站 Humanizer 内容优化与复核

日期：2026-10-01。范围：本地项目 `D:/lzz/lzz/_react`，81 个 sitemap 页面。未部署。

## 执行结果

- 检查 81 个页面；64 个页面的渲染正文发生变化，17 个页面保留原文。
- 修改 24 个源文件，覆盖页面、共享组件和编辑内容数据。原始 `catalog.json` 未修改。
- 35 个产品页分别重写工程标题和选型重点；81 条相关产品说明改为具体差异，去掉反复出现的 `Compare ... when ...` 长句。
- 10 个能力页保留服务范围、材料与工艺信息，调整章节标题及部分范围介绍，区分车削、铣削、多轴、铸件、金属和塑料的决策重点。
- 公司、工厂和质量页合并重复介绍及检验说明；采购指南改为直接描述 RFQ、工艺、材料、原型和批量主题的标题。
- 公司新闻删除对照片的空泛总结，保留事件、日期、地点和可从原始素材确认的活动。
- 提取的正文块由 3,219 减至 3,085。该数字是 HTML 内容块数量，不是字数或 SEO 评分。

## 编辑取舍

| 页面类型 | 用户目的 | 处理方式 |
| --- | --- | --- |
| 首页 | 理解公司业务并选择入口 | 用实际工艺、材料与加工范围替换泛泛介绍；保持简洁 |
| 产品列表 | 按形状、工艺、材料找到产品 | 保留分类和产品名称，不增加 SEO 长段落 |
| 产品详情 | 比较几何特征并准备图纸 | 每个产品保留独立的技术重点；压缩重复 CTA 与图纸说明 |
| 能力页 | 判断工艺适用性和报价所需信息 | 强调装夹、刀具可达性、接口、材料及检验条件 |
| 加工研究 | 看懂照片中的形状和工序 | 改写口号式标题；保留照片来源及证据边界 |
| About / Factory / Quality | 审查供应商、设备及质量流程 | 用具体活动和检查对象表达；合并重复内容 |
| FAQ | 解决报价、交期、检验和运输疑问 | 保留 11 个问题及回答、结构化数据；精简页首并删除重复副标题 |
| Resources | 完成采购判断与文件准备 | 明确文章主题；删去清单前后重复的介绍和总结 |
| Contact / Quote / Privacy | 联系、准备草稿、理解数据处理 | 原有说明已准确，保留业务行为和隐私文本 |

## 第二轮 Humanize Review

| 自检项 | 结果及保留边界 |
| --- | --- |
| 明显 AI 表达 | 已改写本轮识别出的口号式标题、指令双句和空泛总结；不使用检测分数证明作者身份 |
| 模板句 | 35 组选型重点和 81 条产品比较说明分别处理；共享导航和操作标签保持一致 |
| 无意义营销词 | 未增加优势、性能或背书；词表扫描未命中所列夸张营销短语 |
| 重复段落 | 删除和合并冗余正文；MOQ、交期条件、照片来源、草稿发送方式仍在相关页面保留 |
| 页面独立性 | 产品以自身接口和几何重点区分；服务页以工艺或材料条件区分；未重构页面模板 |
| 是否回答用户问题 | 内容围绕图纸、材料、装夹、验收、数量和交付；未添加填充性小节 |
| 业务事实 | MOQ 1 件、7–14 个工作日的起算及表面处理范围、运输另计、ISO 9001、设备及公司数据均保留 |
| 未经证实的新事实 | 未新增客户、认证细节、精度承诺、性能结果或交付记录；保留照片不能证明实测结果的边界 |
| SEO 实体 | 产品名称、服务主题及材料牌号保留；逐页 title、description、canonical 完全一致 |
| H1 / H2 | 用加工和采购主题替换抽象口号；保留标题层级和核心主题 |
| FAQ | 原有问题、回答及 FAQ Schema 保留；条件式公差说明未改成普遍保证 |
| CTA | 明确要求报价或准备 RFQ 邮件；仍由用户在邮件应用添加附件并发送 |
| 填充段落 | 删除新闻照片总结、重复清单引言和部分重复介绍；技术清单未为追求整齐而缩减 |
| 全站语气 | 保持专业、直接、克制；需要固定表达的规则统一，具体技术内容按页面分别表达 |
