## 三种页面的阅读顺序

**首页：先识别业务，再用实物选择。** 保持 Custom CNC、杭州、原型 / 小批量的真实定位。大幅加工概念建立氛围；不对称实物索引将叶轮、壳体、销类和批量形态分工呈现。两个真实装夹阶段解释“形状背后的工艺”，车间照片与来源事实随后建立信任，MOQ / 交期完整条件和绘图输入构成最后一步。

**能力目录：先选路径。** 不增加无信息的品牌大首屏，开头直接给出按工艺、材料、阶段的锚点。四种工艺用可比较的实物入口；材料区以通用原料静物和四种真实材料入口形成主次；项目阶段用说明加示意图，真实装夹和 RFQ 输入放在后半部。11 条业务入口全保留。

**铣削详情：先看适用实物，再读技术条件。** 首屏使用真实圆形件，随后展示壳体与曲面盖。两次装夹放进同一深色章节，照片和说明一一对应。刀具可达性示意引入几何讨论，材料处理表、特征 / 图纸 / 检验表维持完整；条件性的 ±0.01mm 与 CMM 资料边界紧邻，不拆成宣传数字。

三页保留原有语义模块及全部有效文字，通过网格、比例、照片重心、背景和阅读宽度重组视觉。详情页没有因追求短页面删去工程条件；移动端更长是完整技术信息保留的结果。

## 图片策略的差异

Penta 有连续拍摄、光线较统一的真实设备与人物照片。LZZ 当前来源混合：原站产品目录、不同年代 / 尺寸的工厂与装夹图，以及已有明确标注的解释性 AI 图。几何和证据保真优先于把所有照片调成同一“广告风格”。

本轮真实执行 ImageGen，新增 3 张通用示意：加工首屏、原料静物、刀具可达性。前两类布局在生成前确定，提示词规定主体安全区、比例和禁止的证据内容。真实零件没有 AI 修图；真实装夹、车间与 CMM 没有重建。最终页面仍保留来源说明，完整 prompt / PNG / WebP 记录见 `IMAGE-REDESIGN-MANIFEST.md`。

## Taste Skill 的应用与明确例外

已读取 `design-taste-frontend`，用其 inspector 实际检查 1440 / 390px 的三页并审查生成的分屏图。用户已明确选定 Penta，故不随机抽取其他风格。先修布局和图片，再修换行与细节；没有为风格评分快速删除技术内容。

初轮发现手机首页三行 H1、静态卡片阴影与页脚分隔，已修为两行、移除静态投影和不必要分隔。保留的例外：

- `eyebrow`：检测器把面积 / 设备 / MOQ / 生产窗口的 `<dt>` 以及 AI 图注当作 kicker；这些是解释数字或来源所必需的语义信息。
- `shadow`：只允许实际浮层菜单；普通卡片静态和悬停都无阴影。
- `focal-point`：目录与服务页采用与 Penta 接近的 64px 技术标题。检测器要求标题约 8.4vw 或单图占视口三分之一，该阈值不适合此处的选路 / 技术首屏。实际截图中主题、实物和主要行动清晰，保留这一有意尺度。

字号角色较多、首页 / 分类轻动效和无视频是剩余 WARN；不等于无溢出、断图或交互错误。技术堆叠表行可能被识别为重复卡片，不能通过删表或删列处理。运行结果、例外和局限完整写入 QA；不宣称未加例外的 Taste 全绿。

## 与参考站仍有的主要距离

1. 真实摄影的连续性和原始分辨率不足。当前选择保留信息与几何，不能仅靠生成图获得真实团队 / 工厂的可信度。需后续补拍设备、操作、检查和完成零件的统一照片。
2. LZZ 的图纸输入、条件与材料表更长，详情页移动端阅读长度明显高于精简营销页。样板以标题、表格和照片节奏缓解，没有删技术内容。
3. 三页已具同一视觉语言，但其余 81 页仍是当前设计。全站共同页头 / 页脚只在样板 flag 下换肤，尚未开展跨页面族推广。
4. 没有添加客户证言、行业背书、交付绩效或实验数据；需要这些内容时仍应由真实、经授权的资料提供。

方向确认的对象是标题尺度、深色章节节奏、LZZ 蓝色行动与照片分工。确认后才按 `PAGE-REDESIGN-PLAN.md` 推广，当前不部署。
