## 当前行为

统计从公开页面加载开始，不需要先点击同意。隐私页提供开启/关闭按钮；关闭选择保存在 `lzz.analytics.consent`，既有 `no` 偏好继续有效。Do Not Track / GPC 在前端及接口两处停止采集。后台、noindex 页面和已识别机器人不进入新默认统计。

客户端向 `POST /api/analytics/aggregate` 提交短批次，服务端按小时及固定维度累加 `analytics_totals`。该表只有小时、事件类型、公开页面、已知产品编号、语言、按钮位置、宽泛来源/渠道、国家、设备类别、内部标记和计数；不保存逐条事件、访客/访问编号、原始 IP、完整 User-Agent、任意 referrer、UTM 原文、资源文件名或表单内容。来源和位置等只接受允许值，页面必须属于正式公开页面清单。

默认浏览不会新建分析 Cookie，也不会为新询盘关联个人浏览轨迹。安全限流仍使用短时、带密钥散列的网络标识，与汇总表分离；管理员登录与内部排除保留必要 Cookie。询盘字段及当前提交页/来源等上下文继续按原询盘接口保存。

## 埋点与口径

| 事件 | 触发 | 汇总含义 |
| --- | --- | --- |
| `page_view` | 公开页面加载 | 浏览次数，每次加载一次 |
| `product_view` | 既有产品详情页加载 | 产品关注次数 |
| `parameters_expand` | 展开技术/设备/检验说明 | 展开次数，不含一般 FAQ |
| `image_view` | 打开共享图片查看器 | 查看次数，不保存资源文件名 |
| `download_click` | 点击下载入口 | 点击次数，不代表完成下载 |
| `quote_click` / `whatsapp_click` / `email_click` | 点击相应联系入口 | 联系点击次数，不是询盘或合格线索 |
| `form_start` | 首次聚焦该页表单 | 开始填写次数，不按人数去重 |
| `form_error` | 前端校验或提交出错 | 触发次数，可能伴随响应丢失后已保存的询盘 |
| 成功询盘 | 服务端实际保存的询盘表记录 | 独立于汇总开关，不允许客户端伪造成功事件 |

数据按服务端收到时的小时归档，后台以北京时间日期展示，当前日截至目前。概览不再给出独立访客、访问会话、回访者或个人转化率，也不把小时汇总与旧版逐访客数据混为同一时间序列。来源、页面、产品、国家等可筛选和排名。联系点击与开始填写属于次数，成功询盘从已保存记录查询；关闭统计仍能提交询盘。

客户端不重放响应不确定的批次，避免在没有事件编号的情况下自动重复计数。网络拦截、关闭统计、页面离开和无法识别的机器人均可能影响计数，汇总量不代表精确人数。
