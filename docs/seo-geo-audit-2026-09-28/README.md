## A. 结论与范围

**现在最值得做的不是增加页面数量，而是让现有页面从“知道要问什么”升级为“能够判断这家供应商是否适合我的订单”。** 基础页面与导航已经比较完整；最大缺口集中在证据、具体适用范围、比较结论、商务执行口径和内容关联准确性。

首批五项优先改进：

1. **Quality 的证据链**：已有流程、CMM 原照、空白报告格式和认证主张，但无公开 ISO 证书详情、有效校准证据、脱敏实测记录。保留已确认认证承诺，补真实资料和申请路径，不能用生成图片补证据。
2. **Factory / 5-axis 的适用范围**：已有设备族、工厂照片和工程问题，但客户无法独立判断设备模式、可加工包络及装夹限制。先发布经过公司核验的设备与项目适用表；没有数据时保留明确的图纸评审入口，不借用同行参数。
3. **材料与工艺比较**：现有指南提供比较维度，仍少有“何时选 A、何时考虑 B、什么条件下不能直接替代”的答案。先扩充现有材料页和工艺比较指南，区分通用材料知识与 LZZ 已确认供货能力。
4. **采购条件与报价范围**：MOQ 和周期已经清楚，不要再次改成待确认。缺少价格组成、检验文件是否另计、付款/变更/不合格处理的公司口径；先在 How to Order 补报价核对表，再链接到询盘，不增加虚假即时报价功能。
5. **关联内容与文案层级**：能力页重复多，零件详情的通用工艺链接有不相关项；原始长名称进入询盘上下文。保留现有 URL 与模板，把产品—工艺—证据的链接改成真正相关，并缩短重复说明。

### 业务定位

- 网站定位为杭州定制 CNC 制造服务商；以图纸/样件、原型和小批量为主，不是标准 SKU 商店。原始厂房及工序照片支持制造现场展示，不能单独证明每种机型/精度/认证范围。
- 核心：铣削、车削、五轴、铸件后加工；铝、不锈钢、铜/黄铜、工程塑料；原型与小批量。铸件加工不等于已证实自有铸造厂。
- 核心客户：研发/机械工程师、技术采购、OEM项目负责人、供应商质量工程师；出口物流由采购/货代协同。具体重点国家及行业收入占比未提供，当前英语国际采购定位，不创建地名批量页。
- 转化目标是**准备邮件草稿并由客户在邮箱发送**。按钮点击、草稿生成、邮箱打开不等于有效询盘。
- 保留业务口径：1件起；图纸与订单确认后7–14个工作日，含表面处理、运输另计；ISO9001公司确认；±0.01mm仅限特征评审参考；2017/1500m²/40+（含辅助设备）；约10万件/月仅参考产能且有条件。审计没有撤销这些承诺，也没有独立认证其履约能力。
