# 图片制作标识清理

用户要求：删除全站与 AI 生成有关的公开标识。本轮仅本地实施，未推送 GitHub、未发布 Cloudflare。

## 实施

- `imagePresentation.ts` 扩展生成／润色标签过滤，覆盖 ImageGen、AI-generated、AI-refined 等图注及替代文字格式。保留对图片主体的描述。
- `productPhotography.ts` 和 `siteImages.ts` 在公开适配层清理制作方式图注。产品目录原先虽不显示标签，但前端数据仍携带 35 条 ImageGen 图注；本轮一并移除。
- 原始素材、内部 JSON 注册表、来源及替换关系不改动。保留教学图纸、假设数值与示例检验的教学身份说明；这些说明不是 AI 制作标签。没有把展示图改称真实生产或检验记录。
- 当前规则已补入 DESIGN.md。

## 验证

- 86 个正式 URL：可见正文、图片替代文字、悬浮标题及无障碍名称无生成标签；全部 216 份构建 HTML（含前端初始化数据）无 ImageGen／AI 生成或润色标识。
- 前后逐页对比：正文、标题、技术表格、图片路径／响应式图源／尺寸／替代文字、所有链接与 SEO 均一致。变化仅在前端携带的制作方式图注与过滤规则。
- 三份图片注册表的 SHA-256 保持一致。
- `npm run check` 通过：0 errors、0 warnings，9 条既有 hints。`npm run build`、`npm run test:site`、`npm run test:seo` 通过。
- 实际浏览器刷新五轴服务页，检查产品目录加载完成后的显示与前端初始化数据，无生成标签、无横向溢出。目录截图为 1280×720。
