# LZZ 独立 UI Refinement：PHASE 1–5 与有限实施清单

2026-09-29。仅依据当前 http://127.0.0.1:4323/ 渲染及当前组件源码；未阅读旧评审、备份或 DESIGN.md。独立设计评估，不是 Impeccable 双代理完整 critique 命令，也未运行其自动 detector。没有修改网站源码。

## PHASE 1 — Understand

LZZ 是面向海外采购与工程人员的英文定制 CNC 制造商网站。产品是按图制造服务，目录展示零件样本，不是现货商城。当前页面强调原型、小批量、从 1 件起订、杭州车间、铣削/车削/五轴/塑料/铸件加工；这些是网站当前内容，本次未外部核实资质或产能。商业目标应是让合适客户提供图纸、材料、数量与验收要求，发起可评估的询价。

主要访问者可按当前任务推断为：工程人员判断工艺与几何匹配；采购人员判断工厂真实性、质量与交付条件；带图客户直接准备询价。该角色划分是设计判断，不是已验证客户研究。

核心内容的决策顺序应为：做什么 → 做过什么形态 → 谁在制造 → 如何验收 → 如何开始。当前首页包含这五类内容，但工厂、检测、工艺和案例篇幅较分散；内页有不少重复解释。网站当前询价是本地生成邮件草稿，再由访客在邮件应用附图发送，不能包装成在线上传或自动送达。

层级分工：首页负责快速资格判断；零件目录负责按形态/材料/工艺找参照；详情负责确认相似几何和需要讨论的制造条件；能力页负责选服务；质量页负责确认验收与记录；询价页负责准备一次完整沟通。

## PHASE 2 — Diagnose

### 值得保留

- 留白、无卡片边框的零件图和真实车间照片已经形成克制的工业气质。字体本身不是主要问题；不应通过换字体、渐变或大幅动画获得所谓高级感。
- 产品详情把形态、材料、检验与询价上下文串联起来；目录明确不是库存销售。真实性边界应保留。
- 红色主要用于行动，正文与图片保持中性。手机端六页均未检测到水平溢出，基础响应式可靠。

### 5 个有影响的主要问题

1. **首页的工厂证据被重复拆开。** Inside LZZ、Machining in Hangzhou、Dimensional inspection、Machining capabilities、From the workshop 连续出现。五轴设备图在能力段与案例段再次出现，浏览节奏相似。用户反复看“我们的车间”，但不是每次都增加同等价值。保留真实宽幅车间图、紧凑公司事实和一个检验入口，工艺与案例各承担独立目的。不要再增加一组证据卡片。
2. **质量页的信息架构最值得精简。** 首屏和 Equipment 重复同一 CMM 图；Inspection records、空白记录示例、Inspection and material documents 再次展开相近要求。移动页高 10,719px。建议一张 CMM 实拍承担设备证明；把仪器/方法合并，记录类别及订单文件统一到一个主段，空白报告仍明确为示意，以 details 折叠深读内容。保留认证/适用范围边界。
3. **目录的次要内容比筛选任务更重。** 12 个精选零件手机单列，之后还有几何入口、案例入口、额外包覆零件/齿轮图库，再到 CTA，合计 11,325px。目录已经有搜索和过滤，不应继续把附加资料当第二个长目录。优先将 AdditionalPartForms 收纳为明确可展开补充；精选移动端先显示 6 项并保留查看全部。不要机械改成两列挤压复杂零件名称与细节。
4. **能力页把同一层级介绍了两次。** 三个“I need…”入口与随后 Five machining services / Choose a material / Plan an order 内容完全对应；手机前三条占据较大阅读距离。保留入口但改为紧凑的页内索引，正文目录尽早进入首屏后的主要视域。不要新增分类卡或更多图标。
5. **询价页反复解释同一个三步操作。** 顶部说明、步骤导航、附件说明、按钮前提示都解释不会自动提交，手机用户在真正开始前读较多系统说明。保留明确边界，但顶部一句概述、附件位置一句操作指引即可；详细说明放在草稿结果位置。主按钮始终称 Prepare email draft，不改成 Send inquiry。表单功能和状态管理无需重做。

### 次级观察

产品详情结构有用，但 Drawing & inspection checklist 后的相关资源多项等权，建议后续按 drawing / inspection / delivery 合为最多三个出口，不在本轮同时扩大范围。现有页面广泛使用相同白底、细线、左右栏，模板感来源是内容没有清楚主次，而不是缺少图形装饰。照片应依照用途选择：实拍证明制造，零件图说明几何，示意图解释抽象方法；本轮不生成新图。

## PHASE 3 — 三个真正不同的方向

| 方向 | 页面组织与核心体验 | 优点 | 代价 |
|---|---|---|---|
| A 工程证据优先 | 首页先清楚定位与零件，再用一组真实工厂/检验证据建立可信度，连接能力与询价；内页用事实、要求、下一步组织 | 最符合海外采购的资格审查与工程风险判断，充分利用现有实拍 | 必须舍弃重复大图和重复解释，而不是单纯缩小字号 |
| B 零件样本优先 | 网站像可筛选的专业样本库；首页把几何与零件放到主体，服务/工厂成为样本旁的上下文 | 对带着参照件来的工程师效率高，产品图形成品牌辨识 | 容易强化现货商城印象，需要持续明确 made-to-drawing；工厂证明退后 |
| C 项目启动优先 | 首页按“有图纸 / 有样件 / 正在选工艺”组织，流程引導到需求清单和邮件草稿 | 帮助早期采购者形成合格需求，转化路径最短 | 对熟练采购可能像问卷工具；目前邮件草稿能力难以支撑完整项目工作台预期 |

## PHASE 4 — 推荐方向与原则

选择 A：工程证据优先。保留当前视觉身份，改动信息重量与出现顺序。B 可用于目录，C 可用于询价说明，但不把三个方向的视觉组件拼在首页。

原则：一个段落只回答一个采购问题；一个事实只在最有用的位置完整展开；实拍先于示意图；红色只强调当前主要行动；段落间留白表达主题切换，相关内容内部距离缩短；移动端重新分配内容优先级，不仅把桌面列堆叠；每个页面都有可见且真实的下一步。

## PHASE 5 — 删除 / 合并 / 简化 / 排序

- 删除：质量页第二次 CMM 图片展示；首页紧邻证据区重复的 process studies 出口。删除展示冗余，不删除事实来源。
- 合并：质量页设备与测量方法；记录与订单文件；首页工厂事实与检测介绍成为同一信任段。
- 简化：能力页三条长任务入口压缩为清楚索引；询价邮件准备说明只在相关步骤出现一次。
- 收纳：目录 AdditionalPartForms 用可展开区保留原内容与图片；不能直接移除原来源图片或业务范围。
- 排序：首页定位 → 精选形态 → 工厂与检验 → 服务与案例 → 材料与询价；质量页概览 → 检验过程 → 方法 → 记录 → 认证。
