## 对用户标注问题的具体修改

1. **加工案例索引**：两次装夹使用两张独立、来源对应的 ImageGen 重做图。保留两种 holding orientation 的区别；补充图位和材料集合的显示比例。
2. **塑料与金属集合**：以清晰横向主图呈现形态，材料、图纸和验收信息集中排布；取消横图与窄竖屏视频硬拼。PE、POM、亚克力板、清洗后金属和 PEEK 均有从原片参考生成的新展示图。原始视频放在可键盘展开的记录区域，保留播放、原片入口和说明，收起时自动暂停。
3. **车削后铣削 / 两次铣削的检验区**：移除旧 180–240px 缩略图约束，检验图与技术说明采用接近等宽的组合；手机顺序为图片、特征说明。
4. **工艺页检验与装夹图**：统一检验区、批量验收、铝件图片组、铸件检验区和塑料工艺参考的实际图幅。按内容使用完整主体，不套用旧竖图尺寸。
5. **公司、运输、指南和目录**：调整工程故事、包装与工艺参考图片组；目录下方 covered parts / gears 的手机图组改为完整单列，避免新图缩成 142px 辅助缩略图。保留零件目录用于快速浏览的产品小缩略图。

技术参数、适用条件、原 URL 和询价草稿流程均保留。没有把生成画面的可见细节用作新的产品参数、工厂规模、测量结果或客户交付事实。
