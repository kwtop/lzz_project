## 视觉定位

窄体粗标题建立加工业务的力度，开放的灰白阅读区承载工程判断；少量深蓝绿照片章节组织节奏。LZZ 原有标志和蓝色行动按钮继续承担品牌识别。白底实物图回答“能否加工类似形态”，真实装夹与工厂照片回答“怎样理解工艺与证据”，用途明确的概念示意图只解释通用加工、材料和刀具可达性。

统一字体、用色、图片品质和交互；模块顺序依页面任务变化。目录优先选路，服务详情优先适用形态和技术条件，指南优先阅读，案例优先来源和过程。普通展示页通常 4–7 个主要模块；技术文章按信息量保留更多章节。

## 图像体系

1. 真实零件保持完整几何与来源身份，使用 `object-fit:contain`；不拉伸、不改孔数、螺纹、轮廓、表面状态和材料身份。
2. 真实工厂、装夹与检验照片可以按版面做保守显示裁切，保留主要设备、工件和夹持关系；原始文件仍在，不生成扩建、补人或增强“能力证据”。
3. 图片图注和ALT直接描述主题、可见内容与实际要求；前台不展示AI、ImageGen、Illustration、Concept或“示意”等制作方式和类别说明。无信息价值的独立标签直接移除。通用图片不作为LZZ工厂、客户零件、订单、测量或证书证据，原始生成与编辑信息保留在内部来源记录。
4. 首页新首屏以工具、切削区域和夹持关系为重心，文字放在独立深色列，避免压住加工主体。原图 3:2，桌面按约正方形显示，手机 340px 高，重心保持中央偏右。
5. 分类材料新增图为 3:2 原图，桌面在方形区域内裁切，手机回到 3:2；四个具体材料入口仍使用原始零件图，示意色泽不等于牌号确认。
6. 服务图纸章节采用 4:3 刀具可达性概念图；实际零件展示、两次装夹与 CMM 继续使用原始来源。
7. 新图导出 480 / 800 / 1440 三档 WebP，原始 PNG、完整 prompt、散列和尺寸保存在 `design/penta-next-20261017/`。首屏图 eager，其余 lazy；设置宽高、`srcset`、`sizes` 和 ALT。

三页分别有 9 / 11 / 7 个正文图像槽位，19 个去重文件路径。图片分工有实物选路、工艺步骤、材料区分、设备证据与解释概念，不能用不同裁切凑“独立图片数量”。重复的同件装夹可以在首页摘要与详情解释中出现，但不应扩散到无关页面。

## 操作与组件

主按钮为蓝底白字、5px 圆角、通常至少 52px 高，标签使用明确任务 `Prepare RFQ email`。次行动为有下划线的文字链接，标明去向；不为每个章节都加双按钮。按钮悬停亮度 .9，按下移动 1px；实物和工艺入口以文字下划线、颜色提示交互，卡片整体保持原位。控件保留可见键盘焦点（3px 蓝色 outline，offset 4px）。

卡片仅用于真实的并列选择，例如工艺入口或实物索引。工艺说明、两次装夹、订单条件和技术段落不用统一重复卡片承载。材料与检验仍是语义表格，手机保留字段标签与每行完整信息；不能截图成图片或删列。

所有页头、子导航、页脚和联系地址来自现有共享组件。桌面保留 `details/summary` 菜单、单组展开、Escape 和失焦关闭；手机点击入口后关闭主菜单。栏目与二级 URL 原样保留，不复制 Penta 的行业、材料或联系导航。

## 动效

正文始终可见，不依赖动画或 JavaScript 才出现。标准动效为章节标题 / 说明 / 照片独立进入，550ms、向上 14px、opacity .8→1；通过 IntersectionObserver 一次触发。实际交互反馈约 180–200ms。动画仅使用 transform / opacity，按钮亮度为短交互反馈，不新增持续视差、滚动劫持或自动轮播。

`prefers-reduced-motion:reduce` 时不注册进入动效，保留完整静态内容。7条原始视频在真实加工实例中保留，开发/构建版均通过实际解码与失败回退；不加入外部工厂视频。

## 验收与实施边界

每类代表页使用 1440 / 1024 / 768 / 390px 全页截图；检查换行、主体裁切、表格、图注、导航、键盘与横向溢出。比较改前改后主题、标题、全部有效链接、关键正文、表格、Canonical、Breadcrumb、Schema、询价身份。新增图片必须真实进入页面，原始图与 prompts 可追溯。

Taste 的数据标签检测会将 `<dt>` 和 AI 图注识别为 eyebrow，本项目保留其必要语义；菜单只保留真实浮层阴影。分类 / 技术内页 64px 标题是参考 Penta 的有意尺度，接受其“没有 8.4vw 展示标题”的提示，不为通过启发式检查放大技术页。其余低动效、字号角色与表格行提示在 QA 中逐项记录。
