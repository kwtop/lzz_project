生成图用于产品形态与设计讨论，不是尺寸、孔位、材质、检验、库存、订单或交付证据。P04没有恢复原片真实技术细节；仍以受控图纸定义几何。P23/P24展示派生有意去除原有铸字，未生成替代编号，原始带字图保留。CAD、设计参考和装配上下文保持原有身份及供货范围说明。

详情保留原照片或原始参考入口；能力页不再把新展示图称为原始实拍。18页图注按对象更新，保留技术责任和批次边界，仅删除P21一句重复描述及图库已不适用的低清展示提示。工厂、来访、证件、检验和视频帧继续保留真实来源。

品牌标志的高清重建候选改变了轮廓，未采用；保留原件，页脚由112px调整为不超过108px原生宽度。没有把生成图冒称源矢量；后续需要更高像素密度时应使用品牌原始SVG或高清母版。
